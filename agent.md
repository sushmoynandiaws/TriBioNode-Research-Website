# agent.md - Execution Guidelines

## Execution & Communication Style

During any coding task, command execution, or debugging workflow, provide real-time, concise step-by-step progress notes, architectural decisions, and findings in Bengali before and between tool executions (Codex-style execution updates). Explain what you are checking, what you discovered, the reasoning behind changes, and file edits/commands executed, keeping the user continuously informed of every step in clear, short notes.

### Bengali Progress Update Guidelines:
1. **Before Tool Execution**: সংক্ষেপে ব্যাখ্যা করুন কী পরীক্ষা বা সম্পাদন করা হচ্ছে এবং তার কারণ।
2. **After Tool Execution / Findings**: টুলের আউটপুট বিশ্লেষণ করে কী পাওয়া গেল এবং পরবর্তী পদক্ষেপ কী তা সংক্ষেপে জানান।
3. **Architectural & Code Decisions**: কোনো কোড পরিবর্তন বা আর্কিটেকচারাল সিদ্ধান্তের পেছনের যুক্তি বাংলায় পরিষ্কারভাবে উপস্থাপন করুন।
4. **Language & Tone**: পেশাদার, সংক্ষিপ্ত এবং সরাসরি কাজের সাথে সম্পর্কিত (Codex-style updates)।
